Interrupted runs retain `raw.jsonl` and progress but are not complete experiments. `finalize-judges.mjs` refuses missing or duplicate claims. The matrix progress is the authoritative status; do not present queued rows as results.

No usable hosted or archive credentials were found in project configuration.

Never run a model-controlled process as root. Before reporting protection, verify the runtime actually replaces builtin bash, test hook-disable/bypass attacks, and complete 20 paired live tasks. That experiment is pending.

To serve the actual network gate, set `TRACEFORGE_MCP_HTTP_TOKEN` (at least 32
random characters), `TRACEFORGE_RECORD_PUBLIC_KEY_FILE`, and the existing API
URL/token outside Git, then run `node dist/mcp-claim-gate-http.js`. It binds to
127.0.0.1:8081 by default; `TRACEFORGE_MCP_HTTP_PORT` can change the port. Keep
this administrator-equivalent local service private. Public exposure requires
authenticated TLS termination and an explicit workspace access policy.

R9: `heldout-loader.mjs --dataset <external.jsonl> --manifest <new.json> --freeze` requires at least ten externally attested families × eight variants; future loads verify the frozen SHA-256. The software checks bytes and declarations, not social independence. `repeat-extraction.mjs --out-dir <fresh> --datasets <comma-separated-files>` performs 3 seeds × 2 models, genuinely unloads before each cold call, follows with warm inference, and retains fallback/errors. Run after judge work on idle fixed hardware. Unadjudicated natural data is rejected. These tools do not imply measurements were completed.
