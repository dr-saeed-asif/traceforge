# Pilot dashboard counts (October 2026)

`dashboard-counts.csv` transcribes the date-level summaries shown in the
TraceForge dashboard screenshots for 4, 5 and 23 October 2026, as reported in
the round-1 manuscript (Table 7). `recompute.mjs` recomputes the totals and
shares quoted in the text.

These are **pilot observations under policy 2.0.0**, transcribed from
screenshots, not raw database exports. They were not re-processed under
policy 2.1.0 because the underlying SQLite sessions are not in this
repository. Authors: re-run `npm run research:export` on the original
database, re-verify under 2.1.0, and replace this file with the export.
